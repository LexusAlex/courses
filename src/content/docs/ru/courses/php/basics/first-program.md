## Чему научимся

- Проверять версию PHP в терминале.
- Создавать и запускать файл с PHP-кодом.
- Выводить текст с помощью `echo`.

## Что понадобится

Текстовый редактор, терминал и установленный **PHP**. Проверь версию:

```sh
php --version
```

В первой строке будет указана установленная версия PHP. Для занятий используй поддерживаемую версию с [официального сайта PHP](https://www.php.net/downloads.php). Если команда не найдена, установи PHP по [официальной инструкции](https://www.php.net/manual/ru/install.php) и добавь его в `PATH`.

:::tip[PHP и сайт курсов]
PHP нужен только для запуска примеров у себя на компьютере. Сам сайт курсов работает на Astro и не выполняет PHP-код в браузере.
:::

## Первая программа

Создай файл `hello.php` в отдельной папке и сохрани его в кодировке UTF-8:

```php title="hello.php"
<?php

echo 'Привет, PHP!', PHP_EOL;
```

Разберём программу:

- `<?php` начинает PHP-код.
- `echo` выводит текст. Текстовые значения записываются в кавычках.
- `PHP_EOL` добавляет перевод строки для текущей операционной системы.
- `;` завершает инструкцию.

В файле, содержащем только PHP-код, закрывающий тег `?>` обычно опускают. Это помогает избежать случайного вывода пробелов после кода.

Открой терминал в папке с файлом и выполни:

```sh
php hello.php
```

Ожидаемый результат:

```text
Привет, PHP!
```

Для этого примера веб-сервер не нужен: PHP запускает файл прямо из терминала. В уроке используется базовый синтаксис языка без привязки к конкретной версии.

## Задание

Измени `hello.php`, чтобы программа выводила две строки:

```text
Я изучаю PHP.
Это моя первая программа.
```

Сохрани файл и снова запусти `php hello.php`. Проверь текст и перенос строки.

<details>
<summary>Показать решение</summary>

```php title="hello.php"
<?php

echo 'Я изучаю PHP.', PHP_EOL;
echo 'Это моя первая программа.', PHP_EOL;
```

</details>

## Проверка себя

1. Что обозначает `<?php`?
2. За что отвечает `echo`?
3. Что изменится, если убрать `PHP_EOL` из первой строки решения?

Когда пример и задание выполнены, отметь **«Урок пройден»** под материалом. Отметка сохраняется в этом браузере и будет общей для русского и английского перевода.
